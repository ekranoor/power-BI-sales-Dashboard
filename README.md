# power-BI-sales-Dashboard
This project is a Sales Analysis Dashboard created using Power BI to analyze sales performance, profit, quantity, and regional trends.
The dashboard helps businesses understand customer segments, product categories, and sales distribution through interactive visualizations.


🚀 Features

Sales analysis by customer segment
Region-wise sales distribution
State-wise sales visualization using maps
Sales trend analysis by order date
Sub-category performance comparison
KPI cards for:
Total Sales
Total Profit
Total Quantity
Discount Analysis

🛠️ Tools & Technologies Used

Power BI
Data Visualization
Data Cleaning
Business Intelligence
Dashboard Design

📊 Dashboard Insights

Consumer segment contributes the highest sales.
Phones and Chairs are top-performing sub-categories.
Regional sales comparison helps identify high-performing areas.
Time-series analysis shows sales growth trends over time.
